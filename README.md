## ✨ Особенности

- Интерфейс в стиле Winamp 5.666
- Поддержка потокового радио (MP3/AAC)
- Поиск по станциям
- Избранные станции
- История прослушивания
- Отображение битрейта
- Кэширование станций
- Горячие клавиши
- Поддержка мобильных устройств
